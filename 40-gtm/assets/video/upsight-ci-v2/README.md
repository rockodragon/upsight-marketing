# UpSight CI-v2 — Killer Loop Homepage Hero

**Format:** 1920×1080 · 30fps · 14 seconds  
**Composition id:** `CiV2`

## Visual

| Zone | What you see |
|------|----------------|
| Left | Moving feed of customer snippets (calls / surveys / video) |
| Center | One cross-customer takeaway locks in |
| Right | Product priority · stakeholder reel · customer story candidate |

## Commands

```bash
cd 05-remotion
npm install
npm run studio          # preview
npm run render          # → out/ci-v2.mp4
```

## Edit copy

`01-script/hero.script.json` — takeaway, snippet quotes, output cards, timing.

## Media

Clips are symlinked from `upsight-conversational-intelligence/04-assets/video/`.
Replace or add files under `04-assets/video/` and update the script.
