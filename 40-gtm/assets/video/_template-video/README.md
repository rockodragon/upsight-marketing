# Video project template

Duplicate this folder for each new video (use `../scripts/new-video.sh`).

## Folder order — work in this sequence

| Step | Folder | Your job |
|------|--------|----------|
| 1 | `01-script/` | Write message, scenes, timing |
| 2 | `02-capture/` | Record raw product footage |
| 3 | `03-audio/` | Add VO and music (optional) |
| 4 | `04-assets/` | Export clean PNGs/MP4s for the edit |
| 5 | `05-remotion/` | Animate, preview, render |

See each folder's `README.md` for details.
