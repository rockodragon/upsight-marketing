# 02-capture

**Step 2** — Raw recordings only. Nothing here goes directly into Remotion.

## Put here

- ScreenStudio exports (`.mov`, `.mp4`)
- OBS / QuickTime full-screen recordings
- Unedited walkthroughs, multiple takes

## Naming convention

```text
2026-07-01-survey-voice-tab-take1.mov
2026-07-01-survey-chat-followup-take2.mov
```

Include **date + feature + take number**.

## Workflow

1. Record in ScreenStudio (or similar)
2. Drop raw file here
3. Review takes, pick the best moments
4. Export trimmed stills → `../04-assets/ui/`
5. Export trimmed clips → `../04-assets/video/`

**Do not** reference `02-capture/` from Remotion code — always use cleaned files from `04-assets/`.
