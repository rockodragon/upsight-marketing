# Prompt: AI Survey Hero Video

**Date:** 2026-07-01  
**Project:** `upsight-ai-survey-hero`  
**Composition:** `AiSurveyHero`

## User request

> what is ScreenshotFrame? ok now i want another one that highlights the rich AI survey capabilities we have that people love to use, because its beautiful, easy to use, and respond in your way - interactive voice, text or chat.
> Make this in a new project folder with a script we can edit later. save both scripts and prompts actually

## Creative brief

- **Format:** 1920×1080, 30fps, ~16s, dark marketing hero (matches UpSight brand)
- **Core message:** UpSight surveys are beautiful, effortless, and let respondents answer their way
- **Differentiators to show:**
  - Beautiful, modern survey UI (not form-builder ugly)
  - Easy — low friction, adaptive follow-ups
  - Interactive modalities: **Voice**, **Text**, **Chat**
- **Tone:** Confident, direct, product-forward — show don't tell
- **Avoid:** "AI-powered survey" generic hype; lead with experience and modality choice
- **CTA:** Start your first smart survey →

## Scene structure

1. **Hook (3s)** — Strike through "boring surveys"; checkbox fatigue pain
2. **Promise (3s)** — "Surveys people actually want to take" + Beautiful / Easy / Interactive
3. **Modes (5s)** — Three cards cycling Voice, Text, Chat with sample UI for each
4. **Product (3s)** — Live survey mockup with adaptive follow-up + completion stats
5. **Close (2s)** — Tagline, modality reminder, amber CTA

## Edit script

All on-screen copy lives in `scripts/ai-survey-hero.script.json`.  
Re-render after edits: `npm run render`

## ScreenshotFrame note

`ScreenshotFrame` (in the original ads repo) wraps a PNG or MP4 from `/public` in a browser chrome frame with scale-pop animation. Drop real product screenshots there when available; this hero uses animated mockups until then.
