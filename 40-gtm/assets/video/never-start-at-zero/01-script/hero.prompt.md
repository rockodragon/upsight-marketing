# Prompt: Never Start at Zero

**Slug:** `never-start-at-zero`  
**Composition:** `NeverStartAtZero` (in `05-remotion`)

## User / business request

> VSL around compounding profiles that never start at zero — the delightful, one-question-at-a-time feel of a conversational ask, with competitive advantages framed as "here's what you can do and why your life is better," never naming names.

## Creative brief

- **Format:** 1920×1080, 30fps, ~0:51 mute-first cut (full spoken VSL is ~2:15 in source)
- **Audience:** operators who already send forms/surveys and feel the reset every time
- **Core message:** Ordinary forms start cold every single time. Yours never do.
- **Tone:** warm, direct, human — conversational-ask simplicity with an intelligence engine underneath
- **CTA:** Send your first ask · getupsight.com
- **Surface:** marketing dark (`#050508`) + amber CTA + sky secondary. Inter / JetBrains Mono. Confident-glide easing.
- **Rule:** never name a competitor. Contrast is the old behavior everyone already recognizes (form → spreadsheet → start at zero).

## Positioning north star

Simple to send. Delightful to answer. But underneath, it's building something a form never could — a customer relationship that gets smarter with every touch. **You never start at zero.**

## Scene structure

1. **Hook (0:00 / 18s)** — lonely spreadsheet row, cursor blinking; the answer dies
2. **Cost (0:18 / 18s)** — not a survey problem, a relationship problem; curious / ready / nudge
3. **Shift (0:36 / 16s)** — the row blooms into a living profile that keeps filling in
4. **Promise (0:52 / 12s)** — ask once, never again; **you never start at zero**
5. **Demo (1:04 / 24s)** — stage at a glance → follow-up in context → book in-thread → voice/video ask
6. **Feeling (1:28 / 16s)** — one link, one question at a time; heard not processed
7. **Proof (1:44 / 20s)** — one survey became a pitch; walk in from everything you already know
8. **CTA (2:04 / 11s)** — compounding profile + Send your first ask
