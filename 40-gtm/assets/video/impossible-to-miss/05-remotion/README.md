# Impossible to Miss — Remotion

75s brand-film skeleton with **FPO** plates (stock/AI stand-ins) and illustrative signal overlays.

```bash
npm install
npm run studio    # scrub ImpossibleToMiss
npm run still     # frame ~900 (turn / mid-ramp)
npm run render    # → out/ImpossibleToMiss.mp4
```

| Scene | Time | FPO |
|-------|------|-----|
| Witness | 0–28s | Four vignette plates, cool grade |
| Turn | 28–48s | Continuous clarity ramp + conversation→profile→next move cards |
| Proof | 48–65s | Reverses + receipts card |
| Land | 65–75s | Wordmark, no CTA |
